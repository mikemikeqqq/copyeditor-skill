# Citation and Reference Review

## Correspondence Audit

Check both directions:

- every in-text author-year citation has a reference entry;
- every reference entry is cited in the manuscript unless it is intentionally limited to an appendix or supplementary section.

Treat automated matching as heuristic. Manually verify institutional authors, legal cases, datasets, websites, same-author same-year suffixes, and citations embedded in Word fields.

## Metadata Checks

Flag, but do not invent corrections for:

- author spelling or ordering differences;
- publication-year conflicts;
- incomplete title, journal, volume, issue, page, article number, DOI, or URL;
- malformed DOI strings;
- duplicate references;
- inconsistent capitalization and journal-title styling;
- inconsistent en dash/hyphen use in page ranges;
- preprint, advance online, and final publication records mixed without explanation.

## Citation Clusters

Follow the specified style. If no style is specified, preserve the manuscript's dominant system and normalize only obvious inconsistencies. Do not reorder or edit citation-manager field content if doing so would break the field.

## Verification

When the user requests external verification, prefer Crossref, the publisher page, DOI resolver, official legal source, or official organizational page. Record verified changes separately from unverified flags.
